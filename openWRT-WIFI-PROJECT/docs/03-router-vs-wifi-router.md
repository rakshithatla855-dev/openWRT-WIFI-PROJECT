# 03 — Router vs Wi-Fi Router

## Routers

- A router is a networking device that connects different networks and routes data packets between them.
- Routers are hardware devices.

**Keywords:**

- Works mainly over wired connections.
- Connects LAN and WAN (internet).
- Uses Ethernet ports.
- No wireless connection is supported.

## Wi-Fi Routers

- A Wi-Fi router is a router **+** wireless access point combined in one device.
- A Wi-Fi router is hardware, not a software component.

**Keywords:**

- Provides wireless connectivity.
- Also has Ethernet ports.
- Allows devices like phones and laptops to connect.
- Used in homes and offices.
