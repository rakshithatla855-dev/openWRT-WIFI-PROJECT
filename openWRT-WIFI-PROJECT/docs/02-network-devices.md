# 02 — Network Devices

- Network devices are the hardware components used to connect, manage, and control a network.
- Network devices support both wired and wireless connections.

## Examples of network devices

- Router
- Switch
- Bridge
- Access Point
- Firewall
- Repeater

## OpenWrt and network devices

- OpenWrt is an open-source Linux operating system for Wi-Fi routers and embedded network devices.
